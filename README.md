# Fluxy 2 — 8-BIT MOBA 3v3

Ретро MOBA в стиле 8-бит на HTML5 Canvas. 3 vs 3, три линии, башни, Нексус, крипы, 6 героев с уникальными скиллами, онлайн-мультиплеер на WebSockets.

![Fluxy 2](https://img.shields.io/badge/FLUXY-2-00ff9c?style=for-the-badge) ![8-BIT](https://img.shields.io/badge/8--BIT-PIXEL-ffe600?style=for-the-badge) ![MOBA 3v3](https://img.shields.io/badge/MOBA-3v3-ff006e?style=for-the-badge)

## 🎮 Играть

### Оффлайн (с ботами)
1. Открой `index.html` в браузере (или `npm run serve` и перейди на http://localhost:3000)
2. `ИГРАТЬ (ОФФЛАЙН)` → выбери героя → `В БОЙ!`
3. Ты + 2 бота vs 3 бота. Карта, башни, волны крипов каждые 25с.

### Онлайн (с друзьями)
```bash
npm install
npm start          # запустит WS на :3001 и HTTP на :3000
# открой http://localhost:3000 на всех устройствах
# введите одинаковый КОД КОМНАТЫ (напр. ROOM1), выберите героев, нажмите ГОТОВ
```
Сервер автоматически добавит ботов до 6 игроков (3v3) при старте.

## 🕹 Управление
- **WASD / Стрелки / Джойстик** — движение
- **Мышь** — прицел
- **ЛКМ / Пробел** — автоатака
- **Q / W / E** — скиллы
- **Shift** — рывок
- На мобиле — левый джойстик + кнопки Q/W/E/⚔

## ♟ Герои (6)

| Герой | Роль | Фишка |
|-------|------|-------|
| **ФЛЮКС** | Универсал | Импульс + щит + рывок |
| **ЭМБЕР** | Маг | Огненный шар с AoE |
| **ТИТАН** | Танк | Оглушение молотом + крепость |
| **ВОЛЬТ** | Стрелок | Двойной выстрел + мина |
| **ФРОСТ** | Контроль | Пробивающее копьё + заморозка |
| **ШЕЙД** | Ассасин | Клинок-бумеранг + невидимость |

Каждый: 3 скилла (Q/W/E), автоатака, прокачка Lv, золото, КД и мана.

## 🗺 Карта
- 3 линии: TOP / MID / BOT
- 4 башни на команду + Нексус (2500 HP)
- Башни бьют в радиусе, крипы идут по линиям
- 3 точки баффов (центр + jungle) — +HP/MP/XP
- Миникарта, таймер, счёт, killfeed

## 🏗 Структура
```
index.html          # меню + canvas
css/style.css       # 8-бит Press Start 2P + CRT
js/
  config.js         # баланс
  data/heroes.js    # 6 героев
  engine/           # renderer, input, audio (WebAudio chiptune)
  game/             # Game, Hero, Minion, Tower/Nexus, Projectile, Map
  network/client.js # WebSocket клиент
  ui/               # меню + HUD
  main.js           # bootstrap
server/server.js    # Node WS лобби 3v3 + static HTTP
package.json
```

## 🔊 Звук
Процедурный 8-бит (WebAudio): выстрелы, хиты, скиллы, смерть, победа/поражение, фоновая арпеджио. Регулируется в Настройках.

## 🛠 Разработка
```bash
npm install
npm run dev    # WS+HTTP
# или только статика:
npx serve .
```

Код — vanilla JS модули, без сборки. Поддержка Chrome/Firefox/Safari, мобилки.
